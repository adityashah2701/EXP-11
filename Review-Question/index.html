Department Laboratories

State-of-the-art computing facilities equipped with high-performance hardware and software

AI & Deep Learning Lab

Configured for training neural networks, computer vision, and NLP research experiments.

  • Equipment: Nvidia RTX 4090 Workstations
  • Software: PyTorch, TensorFlow, CUDA
  • Capacity: 35 Workstations
Cybersecurity & Forensics Lab

Dedicated sandboxed environment for network traffic auditing, ethical hacking, and vulnerability testing.

  • Equipment: Isolated GigE VLAN, Kali rigs
  • Software: Wireshark, Metasploit, Snort
  • Capacity: 35 Workstations
Cloud & Distributed Systems Lab

Hands-on microservices orchestration, containerization, and distributed database experiments.

  • Equipment: Local Kubernetes cluster server
  • Software: Docker, K8s, OpenStack
  • Capacity: 40 Workstations
Software Development Lab

Focused on Web Technologies, Full Stack frameworks, mobile applications, and Agile development.

  • Equipment: Core i7 Systems, Dual Displays
  • Software: VS Code, Node.js, PostgreSQL
  • Capacity: 40 Workstations
Database & Big Data Lab

High-speed data querying, data warehousing, Hadoop ecosystems, and analytics pipelines.

  • Equipment: High-RAM Dell Precision units
  • Software: Oracle 21c, MongoDB, Apache Spark
  • Capacity: 35 Workstations
Project & Innovation Lab

Open 24x7 for final-year capstone projects, hackathon prototypes, and startup incubator teams.

  • Equipment: Raspberry Pi, IoT kits, 3D Printer
  • Software: Embedded IDEs, Git server
  • Capacity: 30 Workstations
